# Netflix Visualization Dashboard

A comprehensive data visualization project that analyzes Netflix's content library using interactive Tableau dashboards and web-based visualization tools.

## 📊 Project Overview

This project provides detailed insights into Netflix's extensive content library, including movies and TV shows. The visualization covers various aspects such as content distribution, ratings, release trends, country-wise content availability, and genre analysis.

## 🎯 Features

- **Interactive Tableau Dashboard**: Comprehensive visualization with multiple views
- **Web-based Interface**: HTML/JavaScript application for easy access
- **Export Functionality**: Generate PDF reports and image exports
- **Responsive Design**: Optimized for different screen sizes
- **Real-time Data**: Direct connection to Tableau Public dashboard

## 📈 Dashboard Insights

The visualization includes analysis of:
- **Content Distribution**: Movies vs TV Shows ratio
- **Rating Analysis**: Content ratings and their distribution
- **Geographic Distribution**: Country-wise content availability
- **Release Trends**: Content release patterns over time
- **Genre Analysis**: Popular genres and their trends
- **Duration Analysis**: Movie and show length patterns

## 📊 Dataset Source

This project uses the **Netflix Movies and TV Shows** dataset from Kaggle:
- **Dataset**: [Netflix Movies and TV Shows](https://www.kaggle.com/datasets/shivamb/netflix-shows)
- **Creator**: Shivam Bansal
- **Last Updated**: 2021
- **Size**: ~2.4 MB
- **Records**: 8,807 movies and TV shows

### Dataset Features
- **Title**: Name of the show/movie
- **Type**: Movie or TV Show
- **Director**: Director of the content
- **Cast**: Main cast members
- **Country**: Country of origin
- **Date Added**: When added to Netflix
- **Release Year**: Original release year
- **Rating**: Content rating
- **Duration**: Length of the content
- **Listed In**: Genres and categories
- **Description**: Brief description of the content

## 🚀 Getting Started

### Prerequisites
- Modern web browser (Chrome, Firefox, Safari, Edge)
- Internet connection (for Tableau dashboard access)

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/subhammoda/NetflixVisualization.git
   ```

2. Navigate to the project directory:
   ```bash
   cd NetflixVisualization
   ```

3. Open `index.html` in your web browser

### Usage
1. **View Dashboard**: Click the link to access the interactive Tableau dashboard
2. **Export PDF**: Use the "Generate PDF" button to export dashboard as PDF
3. **Export Image**: Use the "Generate Image" button to export dashboard as image
4. **Interactive Features**: Explore different filters and views in the Tableau dashboard

## 📊 Dashboard Features

### Interactive Elements
- **Filters**: Filter by type, country, rating, release year
- **Drill-down**: Click on elements to explore detailed information
- **Tooltips**: Hover over data points for additional information
- **Export Options**: Download dashboard as PDF or image

### Visualization Types
- **Bar Charts**: Content distribution and ratings
- **Maps**: Geographic distribution of content
- **Line Charts**: Release trends over time
- **Pie Charts**: Genre and type distribution
- **Tables**: Detailed data views

## 🔍 Key Insights

Based on the analysis of Netflix's content library:

1. **Content Distribution**: Netflix has a balanced mix of movies and TV shows
2. **Geographic Diversity**: Content from various countries worldwide
3. **Rating Distribution**: Wide range of content ratings for different audiences
4. **Release Trends**: Content spanning several decades
